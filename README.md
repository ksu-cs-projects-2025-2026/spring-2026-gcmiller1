User needs
	- Visual Studio with .NET desktop development and ASP.NET workloads
	- Twilio Subscription
	- Twilio phone number
	- Public server URL or ngrok URL, replace URLs in server and one string in application code for the connection URL
Set these environment variables:
	- TWILIO_ACCOUNT_SID
	- TWILIO_AUTH_TOKEN
	- TWILIO_PHONE_NUMBER
- Twilio webhooks must point to the deployed server
- Run server, then run app
